Nexus agora está configurado para usar a Ollama Cloud, compatível com a API da OpenAI. O endpoint padrão é https://ollama.com/v1 e o modelo padrão é gemma4:31b. A chave fica salva apenas no localStorage do seu navegador.

Padrão definido para Ollama Cloud: https://ollama.com/v1.

No Python, essa chave vem de os.environ["OLLAMA_API_KEY"]. No navegador, cole a chave aqui.

Atenção: não publique este HTML com sua chave já salva. Como o site roda no navegador, qualquer chave usada no front-end pode ficar exposta para quem tiver acesso ao dispositivo ou ao código.
